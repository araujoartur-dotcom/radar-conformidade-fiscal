

No Supabase, tanto a **NF-e** quanto o **CT-e** (e também a **NFS-e**) são gravados e unificados na tabela **`public.dfe_documentos`**, diferenciados pela coluna **`tipo_doc`**.

Abaixo estão os `SELECTs` prontos para você copiar e rodar no SQL Editor do Supabase:

---

### 1. Visão Geral (Últimos Documentos Capturados - NFe e CTe)
Exibe os 50 documentos mais recentes com emitente, destinatário, valores e status de manifestação:

```sql
SELECT 
    tipo_doc,
    numero_serie,
    chave_acesso,
    data_emissao,
    fornecedor_razao AS emitente,
    cliente_razao AS destinatario,
    valor_total,
    situacao_manifestacao,
    created_at
FROM public.dfe_documentos
ORDER BY created_at DESC
LIMIT 50;
```

---

### 2. Consultar Apenas NF-e (Mercadorias)
Filtra somente notas fiscais de produtos (entradas de fornecedores ou saídas):

```sql
SELECT 
    numero_serie,
    chave_acesso,
    data_emissao,
    fornecedor_cnpj,
    fornecedor_razao,
    fornecedor_uf,
    valor_total,
    valor_icms,
    valor_ipi,
    situacao_manifestacao,
    status_sefaz,
    created_at
FROM public.dfe_documentos
WHERE tipo_doc = 'NFe'
ORDER BY data_emissao DESC;
```

---

### 3. Consultar Apenas CT-e (Conhecimento de Transporte / Fretes)
Filtra os conhecimentos de fretes emitidos por transportadoras contra o seu CNPJ:

```sql
SELECT 
    numero_serie,
    chave_acesso,
    data_emissao,
    fornecedor_cnpj AS transportador_cnpj,
    fornecedor_razao AS transportadora,
    cliente_razao AS tomador_frete,
    valor_total AS valor_frete,
    valor_icms,
    created_at
FROM public.dfe_documentos
WHERE tipo_doc = 'CTe'
ORDER BY data_emissao DESC;
```

---

### 4. Resumo Consolidado (Total de Documentos e Valor por Tipo)
Para ver rapidamente a volumetria da sua base no Supabase:

```sql
SELECT 
    tipo_doc, 
    COUNT(*) AS total_documentos, 
    TO_CHAR(SUM(valor_total), 'L999G999G999D99') AS valor_total_acumulado
FROM public.dfe_documentos
GROUP BY tipo_doc;
```

---

### 5. Consultar Itens / Produtos de uma Nota Específica
Se quiser ver os itens desmembrados (NCM, CFOP, quantidade, alíquotas) de uma NF-e:

```sql
SELECT 
    i.item_nro,
    i.codigo_item,
    i.descricao_item,
    i.ncm,
    i.cfop,
    i.quantidade,
    i.valor_unitario,
    i.valor_liquido_item,
    i.valor_icms
FROM public.dfe_itens i
JOIN public.dfe_documentos d ON d.id = i.documento_id
WHERE d.chave_acesso = 'COLE_A_CHAVE_DE_44_DIGITOS_AQUI'
ORDER BY i.item_nro ASC;
```

Você pode consultar os dados gravados no Supabase de duas maneiras muito simples: pelo Painel Web (Navegador) ou direto pelo Terminal aqui do seu ambiente.

Método 1: Pelo Painel Web do Supabase (Navegador)
Acesse o seu projeto no Supabase: 👉 https://supabase.com/dashboard/project/vhkkmklzsstoxoenpyua

No menu lateral esquerdo, você tem duas opções:

Opção A — Table Editor (Visual estilo Excel)
Clique no ícone de tabela (Table Editor) no menu lateral esquerdo.
Selecione a tabela conectores_municipais.
Você verá todos os 77 municípios listados em formato de planilha.
Dá para ordenar por municipio, uf ou provedor.
Dá para usar a barra de busca ou clicar em "Filter" (por exemplo: uf = MG).
Opção B — SQL Editor (Consultas Customizadas)
Clique no ícone de terminal (SQL Editor) no menu lateral esquerdo.
Clique em "+ New query" (Nova consulta).

Cole qualquer um dos SELECTs prontos abaixo e clique em "Run" (ou aperte Ctrl + Enter):

1. Conferir o total de prefeituras cadastradas (deve retornar 77):
sql
SELECT COUNT(*) AS total_conectores 
FROM public.conectores_municipais;

2. Ver todas as 77 cidades com UF, Provedor e Endpoint:
sql
SELECT 
    uf, 
    municipio, 
    ibge, 
    provedor, 
    tecnologia, 
    endpoint_producao,
    status
FROM public.conectores_municipais
ORDER BY uf ASC, municipio ASC;



3. Ver apenas cidades de um estado específico (Ex: Minas Gerais):
sql
SELECT ibge, municipio, provedor, tecnologia, endpoint_producao 
FROM public.conectores_municipais 
WHERE uf = 'MG' 
ORDER BY municipio ASC;

4. Pesquisar por nome de cidade (Ex: Ipatinga ou Cuiabá):
sql
SELECT * 
FROM public.conectores_municipais 
WHERE municipio ILIKE '%Ipatinga%' OR municipio ILIKE '%Cuiabá%';

5. Ver o resumo de quantidade por Provedor:
sql
SELECT provedor, COUNT(*) as qtd 
FROM public.conectores_municipais 
GROUP BY provedor 
ORDER BY qtd DESC;

6. Consultar Notas Fiscais de Serviços (NFS-e) já capturadas:
sql
SELECT 
    tipo_doc,
    numero_serie,
    chave_acesso,
    data_emissao,
    fornecedor_razao AS prestador,
    cliente_razao AS tomador,
    valor_total,
    created_at
FROM public.dfe_documentos
WHERE tipo_doc = 'NFSe'
ORDER BY created_at DESC;


Método 2: Consulta Rápida pelo Terminal (sem abrir o navegador)
Se quiser consultar o Supabase diretamente pelo terminal do VS Code / PowerShell, basta rodar:

powershell
npx tsx -e "
import { getSupabaseAdmin } from './server/db/supabase';
async function test() {
  const supabase = getSupabaseAdmin();
  const { data, count } = await supabase.from('conectores_municipais').select('uf, municipio, provedor', { count: 'exact' });
  console.log('Total de conectores no Supabase:', count);
  console.table(data.slice(0, 15)); // Mostra os 15 primeiros
}
test();
"
